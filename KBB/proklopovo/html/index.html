TCP/UDP


— Transmission Control Protocol

— garance spolehlivého připojení — retransmission, reordering…

— dělění dat z aplikační vrstvy do segmentů (MTU — maximum transmission unit)

— pořadová čísla paketu

— 3w handshake — datagram s příznakem SYN, náhodné pořadové číslo x (klient) —> SYN ACK, náhodné číslo y, x+1 (server) —> ACK, x+1, y+1

— SYN flood (podmínkou je, že server alokuje prostředky před obdržením ACK)

— ukončení spojení — FIN, x (klient) —> ACK, x+1, FIN, y (server) —> ACK y+1 (klient)


— User Datagram Protocol

— negarantuje spolehlivý přenos (neřeší, zdali druhá strana paket obdržela) —> bez záruky doručení

— neřeší pořadí paketů

— značně jednodušší
